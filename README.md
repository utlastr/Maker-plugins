# Maker 插件 3.1.0

## 内部安装与自动更新

Windows 安装包解压后运行 `Install.cmd`，无须管理员权限、Node 或 Codex。
首次在浏览器扩展页开启开发者模式，加载安装器显示的 extension 文件夹。
安装器只向当前用户注册本地更新器；之后启用扩展、启动浏览器或打开 Maker 画布时检查更新。
需要能读取的 GitHub Releases 下载地址。未配置仓库时安装器会询问 `OWNER/REPOSITORY`。
本发行方案使用公开 Release 附件，不把发布者 PAT 分发给使用者；这不提供下载访问控制。
检查失败保留当前版本；发现新版本，验证 RSA 签名及 SHA-256，再等待任务结束和画布保存后更新。
每次替换前备份扩展文件，替换失败恢复备份；数据留在原扩展的浏览器存储。
升级后若原画布未自动刷新，先保存再刷新页面。
发行包固定扩展 ID；它与以前本地开发目录的 ID 不同，旧用户切换前需备份原画布数据。

### 发布新版

发布机安装 Node 与 GitHub CLI，先执行 `gh auth login` 完成本人授权。
执行 `powershell -File scripts/publish.ps1 -Public`，创建 `Maker-plugins` 仓库并发布签名安装包。
GitHub 仓库路径使用 ASCII 名称，项目展示名称为“Maker 插件”。
签名私钥保存在发布者用户目录 `.maker-workflow-publisher/signing.pem`，不进入仓库或安装包。
后续修改扩展版本号，再执行同一发布命令；务必保留该私钥，否则既有安装器不会信任新签名。
仅打包执行 `node scripts/package-release.cjs OWNER/REPOSITORY`，输出位于 dist。
首次安装及自动更新流程尚未进行浏览器到本地程序的端到端验收。

节点直接显示在 Maker 自由画布中。插件独立拥有卡片、数据、创建、编辑、拖动、
尺寸、选择、删除、撤销、连接及结果展示，不创建或改写官方便签、图片卡片。
界面采用官方卡片的配色、边框、标题栏和菜单样式。

## 节点与连接

| 节点 | 输入 | 输出 |
| --- | --- | --- |
| 通用提示词 | 无 | 通用要求 |
| 任务列表 | 无 | 任务列表 |
| 参考图片 | 无 | 参考图片列表 |
| 透明化 | 一个输入口，接收参考图片或生成结果 | 透明 PNG 图片列表，可继续接入生图或展示 |
| 图片生成 | 一个输入口，可连接多个来源 | 图片结果列表 |
| 图片展示 | 一个输入口，可连接多个结果来源 | 无 |

输入口为蓝色，输出口为橙色。输出口可分给多个下游。
从输出口拖到输入口；也支持依次点击输出口、输入口。
点击输入口可查看、调整顺序、断开其连接。

多个通用提示词按连接顺序拼接，多个任务列表按连接顺序合并。
每行一条任务，可填写 `名称 | 描述`，合并后每批最多 100 条。
任务列表初始显示一条空输入行；下方加号新增，行右侧叉号删除。
粘贴多行会自动拆成多条任务，去除 `1.`、`一、`、`(1)` 等行首序号。
参考图片按连接顺序合并并去重，数量由所选官方模型限制。
接入上游任务或参考图时，它们覆盖生成节点的本地默认值；断开后恢复本地值。
通用提示词允许为空，空内容直接忽略；任务描述与连接的参考图片仍需有效。

空白处右键展开「新建图片卡片」创建节点。
卡片标题栏拖动，右下角调整尺寸，右上角关闭。
选中卡片或连线后可删除；卡片可复制，编辑可撤销、重做。
图片展示支持放大、单图下载和 ZIP 下载。
展示卡和结果弹窗按容器尺寸自动计算每页容量，页数随实际图片数量变化。
单张直接展示并下载，不显示筛选、选择和分页。10 张起显示勾选与全选。
不足 10 张且有多页时每 4 秒自动翻页，鼠标停留、编辑或手动翻页时暂停。
生成进度更新时跟随最新出图。单张直接保存图片，多张才打包 ZIP。
下载使用官方文件保存流程，保留图片原格式，不再显示 PNG/JPG/原图选项。
大图支持关闭按钮、Esc 和点击遮罩关闭。
本机官方图片导出接口没有 PSD 格式，本版不提供 PSD 导出。
连接展示节点只读取已有结果，不触发生图。
生成出图后自动连接一张展示卡；已经连接的展示卡继续更新，不重复创建。
生成卡的「查看结果」可以直接打开已生成图片，即使展示卡位于屏幕外也能查看。
连线使用水平切线的三次贝塞尔曲线，包含拖线时的预览线，不采用直角路径。
连线使用独立的 12px 点击命中区；输入口接线允许在圆点周围一倍宽高内松手。
空白处拖动框选卡片与连线，Delete 批量删除，沿用既有撤销和重做逻辑。

## 执行边界

只有点击生成节点的「生成」才向官方服务提交任务。
模型列表、尺寸计算、图片导入、生成、查询和结果落盘均调用 Maker 官方 SDK/服务。
插件不自行实现积分扣费，不通过模拟点击官方按钮或改写请求执行生成。
官方返回处理中时只查询原请求；未知结果停止后续提交，不自动重试生图。
点击取消立即结束本地等待并取消后续任务，显示“已取消”，已完成图片保留。
同时请求官方取消标记；尚未返回任务编号时，在原请求返回编号后补发取消。
官方服务可能继续完成已提交的远端计算，不保证取消能撤回计算或退还积分。
展示与分页只包含实际成功的图片，不将已取消、排队或失败任务计算成图片。
参考图片支持拖入 PNG/JPG/WebP 文件；网页图片链接受来源跨域限制，失败时显示原因。
透明化使用 Maker 官方 createBackgroundRemoval 程序识别纯色背景并处理边缘杂色，
保存为独立 PNG，原图保留，不调用 AI 生图；复杂背景可能无法自动识别。
接入透明化节点时，生成完成自动执行透明化，再输出到展示；不再自动旁路展示原图。
已有的生成到展示直连会转接到透明化输出。连接已有图片时立即处理，无需重新生图。
每张输入按来源路径缓存透明化成功结果，后续出图不会重复处理已完成图片。
透明化失败会显示错误并停止当前链路，不用原图代替处理结果。
透明 PNG 必须同时包含透明像素及可见前景才标记成功；旧缓存自动重新处理。
重复的同源展示连接合并为一个，无其他来源的冗余展示卡移除。

## 架构

- `graph.js`：唯一节点定义及状态模型，包含位置、尺寸、配置、连线和任务结果。
- `canvas.js`：独立 Shadow DOM 节点层；节点按 ID 保留，拖动只更新坐标。
- `maker.js`：唯一官方 SDK 适配层，提供资源、生成和只读样式、连线布局能力。
- `ownership.js`：持久记录插件任务归属，防止官方恢复流程把插件结果另建为平台卡片。

插件只读取官方画布的视口变换，不参与官方卡片的渲染生命周期。
卡片没有“便签”“生成草图”或“工作流”之类来自宿主的替换标题。
模型按项目和画布保存在扩展存储中，不随 Maker 模板 ZIP、Git 或云项目自动同步。
展示使用官方画布缓存的 `resultAssetPath`；发布目录的文件路径不能直接当作画布图片 URL。
加载画布时会按原请求编号恢复已有结果和缓存路径，不重新生图。
插件归属的生成记录只从官方卡片恢复视图中过滤；官方生成记录、源文件仍保留。
旧插件的已知节点会复制到独立数据模型；原始记录保留，仅隐藏对应旧显示。
Maker 未保存或仍有任务执行时，安装器不强制刷新页面。
正在生成时，开发重载工具会延后重载扩展，避免使当前生成上下文失效。

按用户要求，本版未运行测试、浏览器功能验收或付费生图。
